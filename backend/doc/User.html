    class User

    Modelo que representa um Usuário do sistema. Pode assumir diferentes papéis (Admin, Professor, Aluno) dependendo do atributo ‘tipo`. Responsável por armazenar as credenciais de acesso e relacionar-se com as criações (templates) ou submissões (respostas).

    Schema Information:

    • Tabela: users

    • Colunas: nome, email, matricula, tipo, password_digest

    Security:

    • Utiliza has_secure_password para criptografar senhas usando o algoritmo BCrypt.

    • Requer a coluna password_digest no banco de dados.

    • Adiciona automaticamente validações de presença para password na criação.
